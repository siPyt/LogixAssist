Conductivity setpoint reminder
- PLC logic is complete offline in MECO11NOV2026.ACD.
- The PLC file has not been downloaded to the controller.

- Nothing in this handoff has been tested on the live unit.

Required new controller tags
  COND_SP_NOMINAL      REAL   1.0    Read Only
  COND_SP_TOL          REAL   0.005  Read Only
  COND_SP_OK           BOOL   0      Read/Write
  MSG_COND_SP_CHANGED  BOOL   0      Read/Write

PLC logic already added to MainProgram > OIT
  Rung 47:
    CMP ABS(AAH_200_SP-COND_SP_NOMINAL)<=COND_SP_TOL -> OTE COND_SP_OK

  Rung 48:
    XIO COND_SP_OK -> OTE MSG_COND_SP_CHANGED

Behavior
- AAH_200_SP within 0.005 of 1.00: MSG_COND_SP_CHANGED = 0.
- AAH_200_SP outside that tolerance, or an invalid REAL: the bit is 1.
- The reminder is not latched.
- Returning AAH_200_SP to 1.00 clears it automatically.
- It does not stop the still or change MCB.
- It does not affect MSS_SHUTDOWN, MSS_ALERT, DSTLT_STORAGE, the horn,
  AUDIBLE_SUMMARY, ACKNOWLEDGE, RESET, or DeltaV.

DeltaV communication work
- DeltaV U1/U2 logic is edited offline in MECO11NOV2026.ACD.
- DV_HB_LOW_EN is intentionally 0.
- Existing HMI screen 99 already handles DeltaV communication loss.
- Do not create the proposed MSG_DV_COMM alarm or a new DeltaV comm-loss
  screen during this HMI task. That proposal was not implemented.
