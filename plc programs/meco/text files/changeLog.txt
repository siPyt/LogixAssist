How it behaves
  - AAH_200_SP is the setpoint the alarm uses (INPUT_MAP rung 22:
    AT_200_EU <= AAH_200_SP). The HMI value AAH_200_SP_O is copied into it
    by SETPOINTS rung 16.
  - Setpoint within 0.005 of 1.00: COND_SP_OK = 1, message off.
  - Any other value, or an invalid REAL (NaN): COND_SP_OK = 0, message on.
  - Re-evaluated every scan, so it comes back after a power cycle or
    download if the setpoint is still wrong. No latch, no acknowledge.
  - Reminder only. It does not touch MCB, MSS_SHUTDOWN, MSS_ALERT, the
    horn / AUDIBLE_SUMMARY, DSTLT_STORAGE, ACKNOWLEDGE / RESET, or any
    DeltaV bit.

Deviation from the proposal text
  The proposal showed "XIO [CMP ...] -> OTE MSG_COND_SP_CHANGED". Logix cannot
  invert a CMP, so a helper bit (COND_SP_OK) was added and the message is
  driven from XIO COND_SP_OK. This also makes an invalid (NaN) setpoint raise
  the reminder, because the compare is false for NaN.
