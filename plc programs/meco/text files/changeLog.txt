How it behaves
  - AAH_200_SP is the setpoint the alarm uses (INPUT_MAP rung 22:
    AT_200_EU <= AAH_200_SP). The HMI value AAH_200_SP_O is copied into it
    by SETPOINTS rung 16.
  - Setpoint within 0.005 of 1.00: COND_SP_OK = 1, message off.
  - Any other value, or an invalid REAL (NaN): COND_SP_OK = 0, message on.
  - Re-evaluated every scan, so it comes back after a power cycle or
    download if the setpoint is still wrong. No latch, no acknowledge.
  - Reminder only. It does not touch MCB, MSS_SHUTDOWN, MSS_ALERT, the
    horn / AUDIBLE_SUMMARY, DSTLT_STORAGE, ACKNOWLEDGE / RESET, or any
    DeltaV bit.

Deviation from the proposal text
  The proposal showed "XIO [CMP ...] -> OTE MSG_COND_SP_CHANGED". Logix cannot
  invert a CMP, so a helper bit (COND_SP_OK) was added and the message is
  driven from XIO COND_SP_OK. This also makes an invalid (NaN) setpoint raise
  the reminder, because the compare is false for NaN.

    PLC_HB_TMR      TIMER  PRE 5000   "PLC heartbeat pulse timer"
                      (Set to 5000 by user 11/17/2026. DELTA_V_READ[1] steps
                       about every 5 s, so DELTA_V_READ[1].0 is 0 for ~5 s

                       state should last >= 3x DeltaV's slowest update.)
    DV_HB_LOW_PEAK  DINT   0          "Longest DeltaV heartbeat low seen (ms)"
  New rungs at the end of DELTA_V (after rung 25; existing rung numbers
  did not move):
    26  XIO HEARTBEAT -> [TON DV_HB_LOW_OUT 6000, TON DV_HB_LOW_LOSS 11000]
    27  XIO PLC_HB_TMR.DN -> TON PLC_HB_TMR 5000
    28  XIC PLC_HB_TMR.DN -> CPT DELTA_V_READ[1] = (DELTA_V_READ[1]+1) MOD 10000
          (27 must stay before 28: the counter steps once per timer cycle,
           0..9999, then wraps.)
        11/17/2026: a bit version (OTE DELTA_V_READ[1].0) was tried because
        the DeltaV engineers are used to bits, then dropped in favor of the
        counter. DeltaV will use bit 0 of the word, DELTA_V_READ[1].0, as
        the PLC heartbeat: the counter goes up by 1 each step, so bit 0 flips
        0,1,0,1 at every step (also across the 9999 -> 0 wrap).
        DeltaV side: alarm "PLC comm lost" if DELTA_V_READ[1].0 does not
        change for about 3x the step time (about 15 s at PRE 5000), and
        sample faster than the step time.
    29  GRT DV_HB_LOW_OUT.ACC > DV_HB_LOW_PEAK -> MOV DV_HB_LOW_OUT.ACC to
          DV_HB_LOW_PEAK  (peak recorder; write 0 to DV_HB_LOW_PEAK to restart)
  Nothing here drives an output except DELTA_V_READ[1] (was unused).
  The new timers are not used by any other rung yet.
  Rung text note: in this Logix version a CMP / CPT typed as neutral text
  swallows everything after the instruction name as its expression. Enter
  the contacts as text and add CMP / CPT from the toolbar. GEQ / GRT / MOV
  as neutral text are fine. Branches in rung text are BST ... NXB ... BND.
