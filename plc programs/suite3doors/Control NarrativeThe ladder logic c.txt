Control NarrativeThe ladder logic controls cleanroom airlock interlocks across the facility using Rockwell Automation 1769-series discrete I/O modules. Each airlock routine follows an identical, deterministic interlocking architecture:   Normal Interlocking & Mutual Exclusion (Unlock Permissive):Magnetic door locks (maglocks) or strikes are controlled by discrete digital outputs (Local:x:O.Data.n).   An unlock output energizes only when:The master interlock/safety permissive is healthy (Local:10:I.Data.15 = 1).   The airlock is not in an emergency release state (*_Emergency_Release_Latch = 0).   All opposing doors sharing the airlock zone are detected closed via normally closed/high door position switches (XIO(Local:x:I.Data.n)).   If any door in the zone opens (DPS = 1), its contact opens, dropping the coil and locking all other doors in the suite.   Door-Ajar Timers & Violation Lockout (*_Airlock_Latch):When a door opens (Local:x:I.Data.n = 1), a dedicated 30-second on-delay timer (TON, Preset = 30000 ms) starts timing.   If the door remains open longer than 30 seconds (Timer.DN = 1), or if multiple opposing doors are forced open simultaneously (evaluated by parallel closed/open combinations), the controller latches *_Airlock_Latch using an OTL instruction.   This latches the local airlock violation bit (*_Violation_MDI_Bit) and energizes the local visual/audible annunciator output on Local:5:O.   The lockout bit also pulses a single-scan one-shot (ONS) to set the latching tag MDI_Violation_*_Bit, driving a secondary room horn/beacon output on Local:2:O or Local:4:O.   Emergency Release Sequence (*_Emergency_Release_Latch):If the local emergency break-glass or release station activates (Local:11:I.Data.n = 1), rung 0 immediately latches *_Emergency_Release_Latch via OTL.   An XIO of this latch in the door release rungs immediately drops power to the maglocks/strikes, failing the doors safe (unlocked).   Global System Reset:Pulsing the common reset pushbutton / supervisory input (Local:8:I.Data.15 = 1) activates an unlatch (OTU) rung across all routines.   This unlatches *_Airlock_Latch and *_Emergency_Release_Latch, clearing annunciator coils and restoring normal interlocking once all doors are physically shut.
