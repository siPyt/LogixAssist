HOW THE PROGRAM IS ORGANIZED
  - MainRoutine calls the R-numbered routines. Number ranges roughly mean:
    R00xx I/O, scaling, pulses, recipe load/save, flags; R01xx macros for individual devices (vac pumps,
    valves, heater, VFDs, recorders, PIDs); R02xx device-group control (aeration, shelf/condenser temp,
    compressors, EEVs, vacuum groups); R03xx alarms, HMI/manual screens, device mode, batch reports,
    maintenance; R04xx permissives, the freeze drying cycle, steam defrost, leak/bellows tests.
  - Config bits live in ARR0500[]. Device macros use ARR1000[] (request/active/enabled/outputs) with a step
    counter in ARR1001[]. Alarm status bits are in ARR3005+ ; manual-screen requests in ARR3010 ;
    device-mode states in ARR3130 ; status/command flags in ARR0510 / ARR0520.
  - Typical device macro pattern: request rung -> start permissives rung -> step machine (0 off, 10 run,
    20 shutdown ...) -> output bits -> alarm macro bits.
  - Interrupt tasks: OneSecInterrupt, _200mSecInterrupt, _50mSecInterrupt (p.2890-2892); PLC_Fault (p.2893).

MainRoutine | p.1462-1487 | 87 rungs
    Top-level routine of `EF1125:MainTask:MainProgram` (IMA Life library v3.1, IMA-NDW 14 Jul 2020, SCL013).

R0001_AnalogInputs | p.1488-1511 | 42 rungs
    Scales every analog input card channel to engineering units and raises the matching probe-fail alarm macro bit (`ALMM_*_FAIL`, in `AnalogInputsBln` `ARR0010`). Standard channels (pressure transmitters PT, temperature probes TE) call the AOI `R0003_AnalogInScaling`, which converts the raw word + status word to a REAL in `AnalogInputsFlt` `ARR0012[n]` and sets device FAIL_HIGH / FAIL_LOW bits in `ARR0030[n]`.

R0002_AnalogOutputs | p.1512 | 3 rungs
    Scales the two analog (0-100 %) output commands used by the freeze dryer onto their raw 4-20 mA / D/A output words. It calls the `R0004_AnalogOutScaling` AOI twice: once for FV66 (an analog control valve) and once for HTR1 (a heater). The engineering-unit commands come from `ARR0022[8]` and `ARR0022[11]` (analog output command array); the AOI writes the scaled raw count directly to the rack output words.

R0008_TimePulses | p.1513-1515 | 16 rungs
    Generates free-running one-scan timing pulses (50 ms, 200 ms, 1 s, 1 min, 1 hour) used by timing/counting logic elsewhere in the program. The 50 ms, 200 ms and 1 s pulses are derived from "cycle interrupt" bits that are set by dedicated routines and cleared here.

R0018_FDRecipeLoadPar | p.1516-1525 | 20 rungs
    Loads the "current" step type and parameter values (Par 1-15, plus Par 3 hours and Par 3 minutes) of the active freeze-drying recipe step from the big recipe storage array `ARR4137` into the working array `ARR4132`.

R0019_FDRecipeSaveSE | p.1526-1536 | 29 rungs
    Saves the "step end" data of the active freeze-drying cycle step into the step-end storage array `ARR4134` (FDStepEndDataFlt). It uses the same indirect-pointer approach as the recipe load routine: a step offset (`FD_REC_SE_STP_OFFST` = active step - 1) plus a per-item base of 0, 50, 100, ... 1300 gives `FD_REC_SE_POINTER`, which indexes `ARR4134`.

R0027_SaveStartEndTimes | p.1537-1543 | 16 rungs
    Handles batch-report "save start time" (SAV_STRT_TIME_*) and "save end data" (SAV_END_DATA_*) requests. While a request bit is on, it reads the PLC wall-clock time (GSV WallClockTime/DateTime) and converts it to a text string with the `R0026_DateToString` AOI into a fixed slot of string array `ARR3113` (even indexes = start times, odd = end times).

R0030_VFDInterface | p.1544-1546 | 9 rungs
    Maps the raw I/O of the screw-compressor VFDs (EtherNet/IP-style adapter tags `VFD1` and `VFD2`) into a UDT array `ARR0305`, one element per VFD, so the rest of the program works with named members. Instance numbers match the COM number (index 0 is a reserved element). Only COM1 and COM2 are mapped in this routine, even though the comment says up to 4 VFDs are supported.

R0051_DigitalInputFlags | p.1547-1556 | 68 rungs
    Copies every physical digital input (from the I/O racks `RACK_51`, `RACK_52`, `RACK_54`, `RACK_55`, `MANIFLD1` and the controller `Local:3` card) into a corresponding internal "flag" bit in the `DigitalInputFlagsBln` bit array `ARR0510`. All other routines use the flag bits instead of the raw I/O addresses, so hardware mapping lives in one place.

R0052_DigitalOutputFlags | p.1557-1566 | 64 rungs
    Last routine called in the scan: copies the internal "command flag" bits of `DigitalOutputFlagsBln` (`ARR0520`) – set by the device control/command routines (mainly R0053_DeviceCommand) – to the physical digital output points on `Local:4`, `RACK_51`, `RACK_52`, `RACK_54`, `RACK_55` and `MANIFLD1`. Every rung is a single flag contact -> output coil (XIC -> OTE, inferred).

R0053_DeviceCommand | p.1567-1591 | 67 rungs
    Central "device command" routine. For every digital output device on the machine it ORs together all the requests from the various control routines (auto-cycle macros, vacuum groups, compressor/pump files, manual-controls screen, loading panels, Device Mode states) into one command flag bit in `DigitalOutputFlagsBln` (`ARR0520`). Config bits (`ARR0500`) select which source applies for the installed equipment.

R0054_ControlPowerStatus | p.1592-1597 | 16 rungs
    Monitors the machine control-power circuit and sequences the recovery after a control power loss or emergency (stop) switch-off.

R0055_AutoCycleStatus | p.1598-1606 | 17 rungs
    Derives the machine-level "which automatic cycle is running" status bits from the active cycle number (`ARR0551[0]`, `CYCLE_NUMBER`) and the individual cycle macros, builds the combined `AUTO_CYCLE_ACTIVE` bit, keeps a cycle elapsed-time clock (hours/minutes/seconds in `ARR0551[2..4]`) that runs while any auto cycle is active, and latches/clears an "Auto cycle aborted" message bit when any cycle's abort-selected bit is set.

R0099_StatusBitsToSCADA | p.1607-1653 | 164 rungs
    Pure data-mapping routine that publishes each macro routine's status to the SCADA/DeltaV data block. Part 1 (rungs 2-83) builds a status word per routine in `ARR0991[<routine number>]` – bit 0 = macro active, bit 1 = macro ready, bit 2 = macro done/complete (unless otherwise noted) – using the routine's `ARR####[0].x` macro bits, gated by system configuration bits (`ARR0500[]`) so only configured equipment reports.

R0100_VP1Dry | p.1654-1662 | 20 rungs

R0135_ShlfFluidCircPumps | p.1820-1830 | 19 rungs

R0143_ShelfRamMvmtNonCLL | p.1842-1852 | 25 rungs

R0151_ChartRecorder | p.1853-1865 | 33 rungs

R0152_DeltaVInterface | p.1866-1879 | 36 rungs

R0153_ShelfTmpControlPID | p.1880-1886 | 16 rungs

It loads the setpoint from the active mode (freeze-dry recipe, performance test, or manual screen), builds the process value (shelf fluid inlet temperature TE201/TE201A, optionally averaged with TE200), and runs the PID every 200 ms.

R0154_FldCircCondCoolPID | p.1887-1894 | 15 rungs

R0199_CondCircPumpRot | p.1895-1903 | 12 rungs

The lead pump is swapped each time a new assignment is made (a freeze-drying cycle start with the macro requested) and when the primary pump fails/low pressure while the macro is ready.

R0200_ChamberAeration | p.1904-1916 | 22 rungs

R0201_CondenserAeration | p.1917-1924 | 16 rungs

R0202_ShelfTempControl | p.1925-1963 | 38 rungs

R0203_ShCircPumpRotation | p.1964-1972 | 12 rungs

R0206_FluidCircCondCool | p.2039-2107 | 33 rungs

R0209_ElecExpVlvShlfCool | p.2108-2156 | 90 rungs

R0210_ElecExpVlvCondCool | p.2157-2216 | 93 rungs

R0028_ValveFailTimer | p.3055-3058 | 4 rungs
